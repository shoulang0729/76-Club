# 76-Club ⛳ ゴルフコンペ集計＆運営Webアプリ

ゴルフコンペの集計・運営をスマホから行うWebアプリ。ダブルペリア（新ペリア）ネットハンディキャップ、グロス/ネット個人戦、チーム対抗戦、ニアピン/ドラコンの個人賞、女性エブリハンデ、追加ゲーム（ステーブルフォード等）に対応。

🔗 **公開URL**: https://shoulang0729.github.io/76-Club/

## 開発の進め方

- **設計** … Mulmo（MulmoClaude）が担当。設計書は [`docs/handoff/`](docs/handoff/) に置く。
- **実装** … VS Code（Claude Code）が担当。設計書に従って実装する。
- 詳細な分担ルールは投資アプリ（`portfolio`）と同じ「設計▶実装は一方通行」方式。

## フェーズ

| Phase | 内容 | 状態 |
|---|---|---|
| **Phase 1** | 幹事1台完結（端末内 localStorage 保存・JSONバックアップ）で全機能を提供 | ✅ 公開中（`index.html`） |
| **Phase 2** | Firebase による全員同時入力・QRコード入室・リアルタイム同期 | 📐 設計中（handoff参照） |

## 機能（Phase 1）

- 選手マスター（氏名・性別）
- ゲーム（コンペ）ごとの設定：コースPar・隠し12ホール・ペリア係数/上限・女性エブリハンデ・参加者・チーム・ニアピン/ドラコンホール・集計競技のON/OFF
- スコア手入力（18ホールグリッド）
- 結果自動集計：ネット個人戦 / グロス個人戦（女性エブリ反映）/ ステーブルフォード / オリンピック / キャロウェイ / 握り(ナッソー) / チーム対抗(グロス/ネット/ホールバイホール/ベスト2ボール) / ニアピン・ドラコン個人賞
- JSONバックアップ書き出し / 読み込み
