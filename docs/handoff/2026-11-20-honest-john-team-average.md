## 1. 保存と互換性

```js
g.honestJohn.teamScoreMode = 'sum' | 'avg';
```

- `newGame`／`newHonestJohn` は `avg`。新規大会は平均方式を標準にする。
- `migrate` は既存ゲームの欠落／未知値を `sum` に補完する。HJオブジェクト自体が無い旧ゲームも `sum`。
- 計算ヘルパー `hjTeamScoreMode(g)` は明示 `avg` のみ平均、それ以外は `sum`。migrate前の旧データにも安全。
- 明示された既存 `sum`／`avg`、hidden、申告、発表フラグは移行で変更しない。移行は反復して同じ結果になる。
- 複製は元の方式を保持。既存大会の修復処理が `newHonestJohn()` を使う場合も、方式を意図せずavgに変えない。
- 11/22の対象バックアップとサンプルだけ `avg` を明示する。日付・大会名で全ゲームを書き換える処理は作らない。
- export/importで方式を保持。保存キーの追加なし。大学対抗の女性every1・共通36は別設定であり本変更では触らない。

## 2. 計算・共通API

- 人数 `count` は全 `teamMembers(g,T)` の人数。入力済み人数や計算できる人数へ縮めない。
- 個人penalty算式は不変。チーム `total = Σ individualPenalty`、`average = total / count`。
- `value = mode==='avg' ? average : total` を順位、同点、種目勝ち点、総合連携の唯一の採用値とする。
- `hjStanding(g)`／`hjDisplayStanding(g)` のrow契約を次のように拡張する。

```js
{ t, members, ready, total, count, average, value, rank }
// total は従来どおり「合計」。average/value は未丸めnumber、未成立ならnull。
```

- 正式4穴／全員18Hと申告／2チーム以上という種目成立条件は不変。1人でも不足なら全体順位・勝者・総合算入なし。
- 暫定側は確定済み0〜4穴で計算し、同じmodeと人数で順位付けする。0〜3穴は暫定表示だけ、正式連携しない。
- 個別チームが完了していても別チーム不足なら全体順位を出さない。空チームは既存の対象外判定を維持、0除算しない。
- `teamWinPoints` は `r.total` から `r.value` へ変更。表示専用丸めを渡さず、順位・勝者と同じ未丸め値で比較する。
- 最小値のチームへ既定1点。同点は従来どおり重みを山分け（2チームなら0.5ずつ）。εで近似同点にしない。
- 合計150/160の場合：sumなら東大勝ち。avgなら東大 `150/6=25`、一橋 `160/7=22.857142…` で一橋勝ち。
- 当該サンプルは他種目を変更せずHJの1点が一橋へ移り、総合は東大2.5／一橋2.5の引分となる。

## 3. 設定・表・変更検出

- HJ設定カードに「大学別の判定：平均／合計」の2択を追加し、現在方式と母数を説明する。既存ナビの再編なし。
- 各大学の選手行→既存の5列合計行→新しい5列平均行の順。列は申告／実打／置換後／差／penaltyを維持。
- 平均5列は各列の合計÷全参加人数。当該列に欠損があれば合計・平均とも `—`。penaltyを平均差から再計算しない。
- 例：2名の差+1/−1なら差平均0だがpenalty平均 `(10+30)/2=20`。0点としてはいけない。
- 平均表示だけ小数第2位へ丸める。計算・保存・出力モデルは丸めない。表示同値でも未丸め差による順位がありうる旨を説明。
- 総合種目表もHJのavgだけ2桁表示とし、既存 `tpEvVal` の他種目／sumの1桁表示を変えない。avgの種目表示名に「平均」を添え、値の意味を単独で読めるようにする。
- 合計・平均行はチーム色の淡色背景で区別。採用基準行だけを強調し、順位・暫定順位・勝者・連携済み勝ち点を載せる。
- avgでは平均行、sumでは合計行が採用基準。もう一方へ順位バッジを重複表示しない。チーム帯・フルネームは維持。
- ルール文／設定注記／帳票タイトルは方式に追随する。ja/zh/enのキー集合と意味を揃える。
- `hjSignature` に `hjTeamScoreMode(g)` を含め、モード変更で連携を解除し抽選回転を停止する。
- 設定setterでも明示的に無効化し、スナップショット未初期化のケースを守る。同じ方式の再指定では解除しない。
- 保存済みの旧発表を読み込んだだけでは解除しない。既存の入力変更検出・抽選世代チェックを維持する。

## 4. 帳票・出力

- **sumの帳票モデル形状と描画は既存のまま保持する**（旧fixture不変）。以下の拡張はavgにだけ適用する。
- avgの `sheetModel.det.honestJohn` に `mode:'avg'` と大学別 `teams` を追加する。個人rowsへ `teamId` を追加し、既存 `total` は合計の意味を維持。同名大学でもIDでグループ化する。
- teamsは `{teamId,name,count,total,average,value,rank,totals,averages}`、末尾2項は表示5列順の未丸め配列。
- 正式成立かつ連携済みだけ個人rows／teamsを返す。未連携・暫定・不足では両方空、公開可能状態を誤表示しない。
- avgの画像帳票は大学ごとに個人明細＋合計＋平均を掲載し、採用方式・人数・平均行の順位を明示する。
- 帳票の行数／必要高さに追加集計行を含め、最終行の欠落を防ぐ。平均の丸めは描画だけで行う。
- 総合種目表にも採用valueが表示され、大学別表・画像・総合の勝者が一致する。
