## 1. 目的 / スコープ（ユーザー確定 2026-08-16）
- ヘッダー右の**ドロップダウン**で **日本語 / 中文 / EN** を常時切替。
- 既定言語＝**日本語**。一度切り替えたら **`localStorage['golfCompe_lang']`** に永続化し次回以降その言語で開く。
- 中国語は**簡体字**（中国本土向け）。
- 翻訳範囲＝**UI文言＋ルール解説＋トースト/確認ダイアログまで全部**（画面に出る固定文字列すべて）。
- **非対象（翻訳しない＝ユーザー入力データはそのまま表示）**: 選手名・チーム名・ゲーム名・コース名・日付・数値・スコア・獲得ポイント・配分額。

## 2. 触ってはいけない範囲（load-bearing）
- **計算関数(§3)・データモデル(§4)・localStorageキー `golfCompe_v1`** は不変。言語状態は**別キー `golfCompe_lang`** に持ち、`golfCompe_v1` には入れない（データと表示言語を分離）。
- 数値・スコア・順位の**桁組み（`tabular-nums`）と値そのもの**は言語非依存。`t()` を通さない。
- 既存のクラス名・`data-tab`・`onclick` グローバル関数名は維持（i18nは textContent 差し替えのみ）。

## 3. アーキテクチャ（単一ファイル向け・軽量）

### 3.1 辞書とアクセサ
```js
// 辞書。キーは名前空間.項目。値は3言語。
const I18N = {
  ja: { 'nav.game':'ゲーム', /* … */ },
  zh: { 'nav.game':'比赛',   /* … */ },
  en: { 'nav.game':'Game',   /* … */ },
};
let LANG = localStorage.getItem('golfCompe_lang') || 'ja';   // 既定 ja

// 翻訳取得。未定義キーは ja にフォールバック→それも無ければキー文字列を返す（空表示にしない）。
// params でプレースホルダ {x} を差し込む（例: t('status.prov',{n:3,N:12})）。
function t(key, params){
  let s = (I18N[LANG] && I18N[LANG][key]) ?? (I18N.ja[key] ?? key);
  if(params) for(const k in params) s = s.split('{'+k+'}').join(params[k]);
  return s;
}
function setLang(l){
  if(!I18N[l]) return;
  LANG = l; localStorage.setItem('golfCompe_lang', l);
  document.documentElement.lang = (l==='zh' ? 'zh-CN' : l);   // <html lang> 更新
  applyStaticI18n();   // 静的HTMLの data-i18n を差し替え
  render();            // 動的画面を現在タブで再描画（既存の全体再描画関数）
}
```

### 3.2 静的HTML（属性ベース）
静的DOM（タブ・ヘッダ・フッタのボタン等）は**属性で宣言**し、まとめて差し替える：
- `data-i18n="key"` … textContent を `t(key)` に
- `data-i18n-ph="key"` … placeholder を `t(key)` に
- `data-i18n-title="key"` … title/aria-label を `t(key)` に
```js
function applyStaticI18n(){
  document.querySelectorAll('[data-i18n]').forEach(el=> el.textContent = t(el.dataset.i18n));
  document.querySelectorAll('[data-i18n-ph]').forEach(el=> el.placeholder = t(el.dataset.i18nPh));
  document.querySelectorAll('[data-i18n-title]').forEach(el=>{ el.title = t(el.dataset.i18nTitle); el.setAttribute('aria-label', t(el.dataset.i18nTitle)); });
}
```
例：
```html
<button data-tab="game"   onclick="go('game')"   data-i18n="nav.game">ゲーム</button>
<button data-tab="score"  onclick="go('score')"  data-i18n="nav.score">スコア入力</button>
```

### 3.3 動的render（`t()` 直呼び）
`renderGame / renderPlayers / renderScore / renderResult / renderScorecard / rl* / renderTeams / renderStanding …` のテンプレートリテラル内の**日本語リテラルを `t('key')` に置換**する。ここが作業量の中心（約900行のscript）。テーブルのヘッダ（選手/OUT/IN/計/HD/Net/順/スコア/得点/ポイント/配分額 等）も対象。
- 合成文字列はプレースホルダ化：`` `${n}/${N}名入力済み` `` → `t('status.entered',{n,N})`。
- 順位表記：`` `${i+1}位` `` → `t('rank.pos',{n:i+1})`（ja `第{n}位`→本アプリは丸数字バッジ主体なので、テキスト順位が要る箇所のみ）。

### 3.4 起動時
既存の初期化（`load()`→初回`render()`）の**直後**に `document.documentElement.lang = (LANG==='zh'?'zh-CN':LANG); applyStaticI18n();` を一度呼ぶ。以降の言語変更は `setLang()` 経由。

### 3.5 フォント（簡体字の字形最適化・任意だが推奨）
既存の本文フォントは `"Noto Sans","Noto Sans JP",sans-serif`（§11.4）。簡体字は日本語字形と一部異なるため、`zh` 選択時のみ簡体字フォントを優先：
```css
html[lang="zh-CN"] body{ font-family:"Noto Sans SC","Noto Sans",system-ui,sans-serif; }
```
（フォント未搭載環境でも sans-serif で表示は可能。必須ではない。）

## 4. 言語切替UI（ヘッダー右ドロップダウン）
`.hdr-row`（index.html:283 付近）の右側、ハンバーガー(`#hambBtn`)の**左隣**に配置。濃色ヘッダに馴染むスタイル。
```html
<select id="langSel" onchange="setLang(this.value)" aria-label="Language"
        style="background:rgba(255,255,255,.12);color:#fff;border:0;border-radius:8px;padding:8px 10px;font-weight:700;min-height:44px">
  <option value="ja">日本語</option>
  <option value="zh">中文</option>
  <option value="en">EN</option>
</select>
```
- 初期表示は現在の `LANG` を選択状態に（起動時に `document.getElementById('langSel').value = LANG`）。
- `<option>` のラベル（日本語/中文/EN）は**自言語表記のまま固定**（翻訳しない＝どの言語でも自分の言語を見つけられる）。
- タッチターゲット 44pt（§11.5 と整合）。

## 8. 実装メモ / 進め方
- **単一ファイル・ESM化しない**方針は継続（inline onclick がグローバル依存）。`I18N`/`t`/`setLang`/`applyStaticI18n` は既存script末尾にグローバル追加。
- 作業順の推奨：①`I18N` 辞書と `t()`/`setLang()`/`applyStaticI18n()` 追加 → ②静的HTMLに `data-i18n` 付与 → ③`render*` のリテラルを `t()` 置換（タブ単位＝game/players/score/result/roulette の順にコミット）→ ④toast/confirm/prompt 置換 → ⑤ルール解説 → ⑥ドロップダウンUI＋起動時初期化。
- **文字列抽出の網羅性**：置換後、`zh` と `en` に切り替えて全タブ・全サブタブ・表彰式リビール・開発者メニュー・幹事メニューまで巡回し、残存日本語を目視で潰す（受け入れ条件の"漏れなし"）。
- テストデータの sample 選手名（山田 等）は**入力データ扱い＝翻訳しない**。ゲーム名「第1回コンペ」等の既定生成文字列を多言語にしたい場合は別途相談（今回スコープ外＝生成時の言語で固定）。
